# Business Insights 360 – Power BI Dashboard

## 📊 Project Overview

Business Insights 360 is an end-to-end Power BI dashboard developed to provide a 360-degree view of business performance across Finance, Sales, Marketing, Supply Chain, and Executive functions.

The project combines data from Excel/CSV files and SQL to transform raw business data into interactive dashboards and actionable insights for data-driven decision-making.

## 🛠️ Tools & Technologies

- Power BI
- SQL
- Microsoft Excel
- Power Query
- DAX
- DAX Studio
- Data Modeling
- Star Schema

## 📌 Dashboard Views

### 💰 Finance View

Analyzes revenue, gross margin, profitability, and overall financial performance.

### 📈 Sales View

Analyzes sales trends, customer performance, products, and markets.

### 📣 Marketing View

Evaluates marketing performance and business contribution.

### 🚚 Supply Chain View

Analyzes supply chain performance and operational metrics.

### 👔 Executive View

Provides high-level KPIs and business insights to support management decision-making.

## 🔍 Key Features

- Interactive Power BI dashboard
- Star schema data model
- DAX measures and calculated columns
- SQL-based data analysis
- Dynamic titles
- Bookmarks and navigation buttons
- Performance optimization using DAX Studio

## 📈 Business Impact

The dashboard provides actionable insights into sales, finance, marketing, and supply chain performance, helping stakeholders identify trends, evaluate profitability, and support data-driven business decisions.
